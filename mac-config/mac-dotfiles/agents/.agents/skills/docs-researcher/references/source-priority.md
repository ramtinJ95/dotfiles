# Source Priority

Use sources in this order:
1. Context7 docs for the target library/framework.
2. Official vendor docs and standards/specification pages.
3. Source code and tests from official repositories.
4. High-quality community sources only when primary docs are insufficient.

Guidelines:
- Prefer explicit versioned references.
- Mark assumptions when docs and repo behavior diverge.
- Link each non-trivial claim to a source.
